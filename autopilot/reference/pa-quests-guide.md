# PA Quest answer key (community guide, Reddit r/SimCompanies 2mo — Ctrl-F the quest text)

Loaded by `act pa_read` ONLY (not every wake). Pick the answer marked BEST. Our own MEASURED
outcomes in pa-quests.md OVERRIDE this list where they differ (DOCTRINE §0: measured > community).
When an offer needs goods we lack, answering is safe — the offer stays open (buy/make, then answer).

## Classic quests (best answer → outcome)
1. Contractor offers 3 free Construction units → "please write him a check" / accept → +3 construction units.
2. Trader sells 4,000 water @$0.13 → "write him a check" (accept) → +4,000 water (resell ~$0.38 = big win).
3. Vineyard wants 200 grapes for $3,000 → give grapes → +$3,000 (only if grapes cheap to us).
4. Sister-in-law at the FPA / inside info → "I do not control multiple accounts" (refuse — rules).
5. Relative wants a job → "submit a resume to HR like everyone else" → employees applaud (fairness, no penalty).
6. Bum sells 3 tablets $100 → take them → +3 tablets.
7. Refugee scientist sells 20 research @$10 → buy → +20 random research (resell).
8. Farmers want seeds @$0.3 → "cannot deal with seeds right now" (decline; only sell if we profit).
9. Charity $1,000 hurricane → "maybe later" (decline — no effect either way).
10. Immigrant workers: 200 sausages → +1 building level. ACCEPT ("when can they start?"). Game picks
    the building. A building level ≫ the food. **MAKE the sausages (Slaughterhouse ~77/h, ~$560 pigs)
    not buy ($2,525).** ⚠ it may upgrade a building we don't want — still usually worth it.
11. Christmas party $500–1,500 → "get back to work!" (decline — party actually costs $2,000, no benefit).
12. Easter eggs, school wants 5,000 @$1.10 → sell if market/own-cost profitable; OR donate 2,500 → +q7 egg.
13. Mafia boss: 2,000 transport, "promised $4,500" → accept ("I'll drive the truck myself") → pays only
    **$1,700** (measured). Worth it only if transport is cheap to us; price it at $1,700 not $4,500.
14. Yearly fair wants fruit+sausages, apples @$2.20 → supply IF profitable at that price.
15. Politician wants money → "Are you for real? (hang up)" (decline — donation has no return).
16. Wall-street derivatives guy $2,000 → "not interested" (decline; accepting nets only +$80).
17. Sales dept wants a party $3,000 → "focus on business" (decline — no penalty).
18. SimConstruction needs 2,000 bricks → send them → next upgrade completes in HALF time (great if upgrading).
19. City event, brother-in-law, $5,000 sponsor → donate → **+1% production/sales speed** (permanent, huge).
    ⚠ if skipped, it recurs at Lv.23 costing $150,000 — take it now if cash allows.
20. Employee found $2,300 envelope → either answer keeps the $2,300, no penalty.
21. Union vote → "negotiate fairly" → union forms, one-time $4,000 (salary text is flavor). Third option
    = 5% production/retail cut. Cheapest is just pay the $4,000.
22. Son wants $1,600 eye-phone → cheaper phone or none (no downside; the $1,600 is wasted).
23. Transport company wants 1 truck for $5,000 → send truck → **+20,000 transport units** bonus (great).
24. Patent lawsuit, settle $10,000 → "fight it" → costs $25,000 but a fund reimburses = break even.
25. Mobile package: 6 smartphones $2,000 → accept → +6 phones.
26. Company BBQ needs 100 steaks → give steaks → a random building INSTANTLY finishes (use when a long
    order/build is running — free time skip).
27. Millionaires fair: 10 watches + 10 necklaces → send → sold for **$40,000** (only if we have them).

## Rule of thumb when an offer is NOT in this list
Judge on the PESSIMISTIC number. Free goods / permanent % boosts / instant-finish / building-level =
take. Donations to politicians/charities/parties = decline (no return). Gambles framed as "great deal"
= usually a trap unless the safe/decline branch gives a gift. Journal any new offer's outcome to
pa-quests.md so we learn it.
