# Metric spec — `realizable.js`: realizable $/building-hour that never rewards unsellable output

Status: FINAL DESIGN, synthesized from the three peer analyses (`.metric-signals.md`,
`.metric-derived.md`, `.metric-oversupply.md`) and **re-verified end-to-end against live data**
(`game-facts.json` gen 2026-07-23T02:06, `board-data.json` gen 2026-07-24T03:25Z,
`knowledge.json`, `market-snapshots.jsonl`, `price-history.jsonl`) on 2026-07-24.
Every number in §6 was computed by the prototype in §9, not copied from a peer doc.

## 0. The one-paragraph thesis

`consumption` and `unitsSoldAnHour` are **both 0** for crude, dough, samosa **and** every aerospace
part, so no direct field separates real from dead (the proven CRITICAL FAILURE). The separator is
the **recipe graph**: propagate each good's *realized terminal demand* up its consumer tree. Seed
that propagation with a **realized leaf** = `consumption` (honest fractional realm draw) unioned with
retail throughput **only where the retail lake actually clears** (non-null price) plus measured
restaurant off-take. This one seed choice simultaneously reproduces the live-probed aerospace figure
(flight-computer **0.0566/h** vs known ~0.057) and keeps crude/dough/carbon-fiber alive. Then discount
the paper rate by **retail elasticity** (saturation band) or **B2B share + exchange oversupply**, so
`realizable$/h = perUnitProfit × realizableRate` and rank by that instead of paper $/h.

---

## 1. The bug this replaces

`industry-report.js:78-81` computes `profitPerHour = (netSell − inputCost) · rate − wage` with
`rate = producedPerHourRaw · 0.8087` — it assumes **every unit a building makes sells at the current
price**. False twice over: (a) the realm only absorbs so much (aerospace: paper $2,600-3,849/bldg-hr
vs realm demand ~0.057/h — a ×34 rocket-engine coefficient standing on a placeholder `unitsSold=1`
satellite), and (b) our own added supply presses the price down (fruit already at saturation ~1.5).
`realizable.js` replaces `rate` with a **realizableRate** haircut and re-sorts on the result.

## 3. Realizable absorption `A(k)` — the three-channel combine

### 3.1 Realized leaf seed (THE decisive choice)

For each good, its *own* realized terminal demand — credit a channel only when it is real:

```
retailClears(k)  = avgPrice != null && avgPrice > 0          # dead-lake gate (kills aircraft's fake "1")
restaurant(k)    = amountSoldRestaurant_last / 24            # measured B2B/catering off-take, units/h
retailTerm(k)    = inRetailFeed(k) ? (retailClears(k) ? max(unitsSoldAnHour(k), consumption(k))
                                                       : consumption(k))
                                   : consumption(k)          # pure-B2B goods: consumption(=0)
leaf L(k)        = retailTerm(k) + restaurant(k)
```

- `max(unitsSold, consumption)` avoids double-counting the retail overlap and takes the honest larger.
- A dead retail lake (aircraft, `avgPrice=null`) contributes **only** its tiny `consumption`
  (satellite 0.0115, single-engine 0.0188…) — this is what makes the aerospace subtree propagate to
  the **true** ~0.057/h, not a fake `unitsSold=1` mirage.
- Samosa (`avgPrice=0`, dead retail) survives on `restaurant = 376 539/24 = 15 689/h`.

### 3.2 Recipe-graph propagation (Leontief backward, verified acyclic — converges ~9 iters)

```
A(k) = L(k) + Σ over every consumer Y of k:  A(Y) · recipe(Y)[k]
```

Fixed-point iterate `A = L + Aᵀ·A` to `maxDelta < 1e-12`. `derived(k) = A(k) − L(k)`.
`A(k)` is the realm's **total realized pull** on k across both channels — the "combine" the brief asks
for. It is a **classifier and headroom base in units/h**, never the dollar ranking (dollars come in §5).

**Verified leaf+propagation reproduces both anchors** (§9 prototype, live data):
flight-computer `derived = 0.0566/h` ≈ known 0.057 (three-digit match) **and**
crude 200/h, dough 13 892/h, carbon-fiber 160/h all stay alive with `consumption = unitsSold = 0`.

## 4. The discount → `realizableRate`

Branch on whether the good has a live retail/restaurant sink. **A good with a clearing retail entry is
governed by its retail lake** (our marginal building sells there); a good with no retail entry is
governed by the **exchange/B2B** lake. This branch is what keeps steak on the low retail track while
crude rides the deep B2B track.

### 4.1 RETAIL / RESTAURANT branch — `inRetailFeed(k) && (retailClears || restaurant>0)`

Verified market physics (holds to 4 dp across all 80 goods + 28-day history):
`demand = clamp(1 − S/2, 0, 1) = m(S)` — the price/sell-through multiplier; saturation is the single
retail oversupply state variable. Accept at most a fractional price drop `τ` from our own adds:

```
A_ret        = (retailClears ? unitsSoldAnHour(k) : 0) + restaurant(k)
headroomSat  = max(0, τ·(2 − S) − k_t·dS)            # τ×distance-to-dead, minus flood / plus drain credit
headroomFlow = headroomSat · A_ret / β                # units/h we can add inside the τ band
realizableRate = min( g, headroomFlow )               # can't sell faster than we make, nor than the band allows
```

Draining lakes (`dS<0`) hand back headroom; flooding lakes (`dS>0`) remove it. `A_ret` uses the retail
sink only — the good's B2B `derived` is satisfied by other producers and must not inflate our
single-building retail rate (this is why steak stays low despite a real downstream B2B tail).

### 4.2 EXCHANGE / B2B branch — no retail entry

```
A_der = derived(k)
priceKeepExch(k) =
    orderBook present : clamp(1 − DoS/DoS_dead, 0, 1),  DoS = bookDepth(±p_band) / A_der / 24
    book stale        : clamp(0.5 + 0.5·slope24h(price-history[k]) / |price|, 0.35, 0.75)   # or 0.6 if is_up else 0.5
realizableRate = min( g, α·A_der ) · priceKeepExch(k)     # one operator claims ≤ α of realm demand
```

Mark `bookStale:true` when falling back (crude/dough/aerospace this cycle). `α` caps the share a single
operator can drain without becoming the oversupply.

## 5. Dollars & the sort key

```
perUnitProfit = price(k)·(1 − FEE) − transportation·price(13) − Σ recipe(k)[x]·price(x)
realizable$/h = perUnitProfit · realizableRate − wage(buildingOf k)
realizableFraction = realizableRate / g     # ∈[0,1]: "how much of the paper is real" — the headline
```

Rank the industry table by `realizable$/h`, **not** paper `profitPerHour`.

## 6. VERDICT taxonomy — exact numeric triggers (evaluated in order)

| Verdict | Trigger (first match wins) | Meaning / action |
|---|---|---|
| **SEASONAL** | `retailSeason \|\| productionSeason` non-null (or accumulator mechanic) | pre-filtered; off-season scarcity price low-level cos can't realize. |
| **MIRAGE(dead-lake)** | `inRetailFeed && !retailClears && restaurant==0` | listed but `avgPrice` null/0, no off-take → `rr=0`. (aircraft k95-99.) |
| **MIRAGE** | B2B & `derived < max(A_mirage=1.0, 0.02·g)` | subtree terminates in non-clearing/near-zero demand → `rr=0`. (aerospace parts 0.03-0.06.) |
| **OVERSUPPLIED** | retail & `S>1.0 && dS ≥ −ε_drain(0.002/day) && S<1.8` | crowded, price-suppressed, flat/flooding → poor scale target (heavily discounted, not killed). (apples S1.49 dS+0.0002.) |
| **B2B-DEEP** | B2B & `derived ≥ A_deep(50)` **OR** retail-dead but `restaurant>0` (restaurant-driven) | real deep durable demand → top scale target. (crude 200, dough 13 892, carbon-fiber 160, samosa 15 689.) |
| **B2B-THIN** | B2B & `A_mirage ≤ derived < A_deep` | genuine but shallow cross-sector demand → credit, low priority. (combustion-engine 9.) |
| **RETAIL-OK** | retail & (`S≤1.0`, or `S>1.0 && dS<−ε_drain` draining) | healthy or price-recovering lake; `rr` still elasticity-limited. High-volume if `A_ret` large. (construction 120; steak draining, low $.) |

`ε_drain = 0.002/day` is what splits **steak (S1.34, dS−0.009 → RETAIL-OK, draining, low $)** from
**apples (S1.49, dS+0.0002 → OVERSUPPLIED)** despite near-equal saturation — the trend, not the level.

## 9. Near-final `realizable.js` (drop-in module — this exact code produced §7)

```js
#!/usr/bin/env node
// realizable.js — realizable $/building-hour that never rewards unsellable output.
// Combines: realized retail leaf + recipe-graph derived B2B demand + oversupply/elasticity discount.
// READ-ONLY. Exports buildRealizable(); run directly for a ranked table + JSON artifact.
//
// Verdicts: RETAIL-OK | B2B-DEEP | B2B-THIN | OVERSUPPLIED | MIRAGE | MIRAGE(dead-lake) | SEASONAL
const fs = require('fs'), path = require('path');
const DIR = '/srv/appdata/chrome-automation/sim';

const C = {                                   // §6/§7 constants — tunable
  L1: 0.8087, FEE: 0.04, TRANSPORT_KIND: 13,
  TAU: 0.12, BETA: 1.0, KT: 5, ALPHA: 0.34,
  A_DEEP: 50, A_MIR: 1.0, EPS_G: 0.02,        // B2B tiers
  S_DEAD: 1.8, EPS_DRAIN: 0.002,              // retail level/trend
  DOS_DEAD: 30, P_BAND: 0.05,
};

function load(factsPath, boardPath, defsPath) {
  const facts = JSON.parse(fs.readFileSync(factsPath, 'utf8'));
  const board = JSON.parse(fs.readFileSync(boardPath, 'utf8'));
  const defs = defsPath ? JSON.parse(fs.readFileSync(defsPath, 'utf8')).resources : null;
  return { R: facts.resources, board, defs };
}

function buildRealizable({
  factsPath = DIR + '/game-facts.json',
  boardPath = DIR + '/board-data.json',
  defsPath = DIR + '/defs.json',
} = {}) {
  const { R, board, defs } = load(factsPath, boardPath, defsPath);
  const kinds = Object.keys(R);
  const nm = k => ((defs && defs[k] && defs[k].image) || 'k' + k).replace(/.*\//, '').replace('.png', '');

  const price = {}, isUp = {};
  for (const t of board.market.ticker) { price[t.kind] = t.price; isUp[t.kind] = t.is_up; }

  // retail feed by dbLetter (max-saturation on collision)
  const retailByDb = {};
  for (const e of board.market.retail) {
    const p = retailByDb[e.dbLetter];
    if (!p || (e.saturation || 0) > (p.saturation || 0)) retailByDb[e.dbLetter] = e;
  }
  const RI = k => {
    const e = retailByDb[R[k].dbLetter];
    if (!e) return { inFeed: false };
    const rd = e.retailData || [], n = rd.length, j = Math.max(0, n - 7);
    const last = rd[n - 1] || {};
    const dS = n >= 2 ? (e.saturation - rd[j].saturation) / Math.max(1, n - 1 - j) : 0;
    return {
      inFeed: true, sat: e.saturation, avgPrice: e.averagePrice,
      clears: e.averagePrice != null && e.averagePrice > 0,
      restH: (last.amountSoldRestaurant || 0) / 24, dS,
    };
  };

  // ---- §3.1 realized leaf ----
  const L = {};
  for (const k of kinds) {
    const cons = R[k].consumption || 0, us = R[k].unitsSoldAnHour || 0, ri = RI(k);
    const retailTerm = ri.inFeed ? (ri.clears ? Math.max(us, cons) : cons) : cons;
    L[k] = retailTerm + (ri.restH || 0);
  }
  // ---- §3.2 reverse graph + Leontief fixed point ----
  const consumers = {};
  for (const y of kinds) for (const [x, m] of Object.entries(R[y].recipe || {}))
    (consumers[x] = consumers[x] || []).push({ y, mult: m });
  let A = Object.assign({}, L);
  for (let it = 0; it < 500; it++) {
    const nA = Object.assign({}, L); let md = 0;
    for (const x of kinds) { const cs = consumers[x]; let a = 0; if (cs) for (const { y, mult } of cs) a += A[y] * mult; nA[x] += a; }
    for (const k of kinds) md = Math.max(md, Math.abs(nA[k] - A[k]));
    A = nA; if (md < 1e-12) break;
  }
  const der = {}; for (const k of kinds) der[k] = A[k] - L[k];

  // ---- exchange oversupply (fallback = bookStale) ----
  const books = (board.coo && board.coo.orderBooks) || (board.cmo && board.cmo.orderBooks) || {};
  const priceKeepExch = k => {
    const bk = books[k];
    if (bk && bk.length) {
      const best = Math.min(...bk.map(o => o.price));
      const depth = bk.filter(o => o.price <= best * (1 + C.P_BAND)).reduce((s, o) => s + o.quantity, 0);
      const dos = depth / Math.max(1e-9, der[k]) / 24;
      return { pk: Math.max(0, Math.min(1, 1 - dos / C.DOS_DEAD)), stale: false };
    }
    return { pk: isUp[k] ? 0.6 : 0.5, stale: true };   // §4.2 fallback
  };

  const perUnitProfit = k => {
    const sell = price[k]; if (sell == null) return null;
    let ic = 0; for (const [x, m] of Object.entries(R[k].recipe || {})) { if (price[x] == null) return null; ic += price[x] * m; }
    const freight = (R[k].transportation || 0) * (price[C.TRANSPORT_KIND] || 0);
    return sell * (1 - C.FEE) - freight - ic;
  };

  // ---- §4/§6 classify ----
  const byKind = {};
  for (const k of kinds) {
    const r = R[k], ri = RI(k), g = (r.ratePerHourRaw || 0) * C.L1, pu = perUnitProfit(k);
    let rr = 0, verdict, channel, bookStale = false;

    if (r.retailSeason || r.productionSeason || r.accumulator) { verdict = 'SEASONAL'; channel = 'season'; }
    else if (ri.inFeed && !ri.clears && (ri.restH || 0) === 0) { verdict = 'MIRAGE(dead-lake)'; channel = 'retail'; }
    else if (ri.inFeed && (ri.clears || ri.restH > 0)) {                      // RETAIL branch
      channel = (ri.restH > 0 && !ri.clears) ? 'restaurant' : 'retail';
      const Aret = (ri.clears ? (r.unitsSoldAnHour || 0) : 0) + (ri.restH || 0);
      const head = Math.max(0, C.TAU * (2 - ri.sat) - C.KT * ri.dS) * Aret / C.BETA;
      rr = Math.min(g, head);
      const S = ri.sat;
      if (ri.restH > 0 && !ri.clears) verdict = 'B2B-DEEP';                   // restaurant-driven king (samosa)
      else if (S >= C.S_DEAD) verdict = 'MIRAGE(dead-lake)', rr = 0;
      else if (S > 1.0 && ri.dS >= -C.EPS_DRAIN) verdict = 'OVERSUPPLIED';    // flat/flooding (apples)
      else verdict = 'RETAIL-OK';                                            // healthy or draining (steak, construction)
    } else {                                                                  // B2B branch
      channel = 'b2b';
      const Ad = der[k];
      if (Ad < Math.max(C.A_MIR, C.EPS_G * g)) { verdict = 'MIRAGE'; rr = 0; }
      else {
        const pke = priceKeepExch(k); bookStale = pke.stale;
        rr = Math.min(g, C.ALPHA * Ad) * pke.pk;
        verdict = Ad >= C.A_DEEP ? 'B2B-DEEP' : 'B2B-THIN';
      }
    }
    const realizable$h = pu == null ? null : pu * rr - 0;   // wage added by caller (has building table)
    byKind[k] = {
      kind: +k, name: nm(k), channel, verdict,
      g: +g.toFixed(3), absorption: +A[k].toFixed(3), derived: +der[k].toFixed(3),
      realizableRate: +rr.toFixed(4), realizableFraction: g > 0 ? +(rr / g).toFixed(4) : 0,
      perUnitProfit: pu == null ? null : +pu.toFixed(3),
      realizablePerHour_preWage: realizable$h == null ? null : +realizable$h.toFixed(1),
      bookStale,
    };
  }
  return { byKind, constants: C, generated: board.generated };
}

module.exports = { buildRealizable, CONSTANTS: C };

// ---- CLI: ranked table + artifact for strategist/board ----
if (require.main === module) {
  const out = buildRealizable();
  const rows = Object.values(out.byKind)
    .filter(r => r.realizablePerHour_preWage != null && r.verdict !== 'SEASONAL')
    .sort((a, b) => b.realizablePerHour_preWage - a.realizablePerHour_preWage);
  const p = (s, n) => String(s).padEnd(n);
  console.log(p('resource', 20) + p('verdict', 20) + p('rr/h', 9) + p('frac', 7) + p('$/h(preWage)', 14) + 'A(total)');
  console.log('-'.repeat(84));
  for (const r of rows.slice(0, Number(process.env.TOP) || 40))
    console.log(p(r.name, 20) + p(r.verdict, 20) + p(r.realizableRate, 9) +
      p(r.realizableFraction, 7) + p('$' + r.realizablePerHour_preWage, 14) + r.absorption);
  fs.writeFileSync(DIR + '/board/.realizable.json', JSON.stringify(out, null, 1));
  console.error('\nwrote board/.realizable.json (' + rows.length + ' scored kinds)');
}
```

## 10. Wiring into `industry-report.js` (replace the paper-$/h sort)

`industry-report.js` currently sorts on `profitPerHour = (netSell − inputCost)·rate − wage`. Change:

1. **Require + build once** (after the `defs`/`cap` loads):
   ```js
   const { buildRealizable } = require('./realizable');
   const RZ = buildRealizable().byKind;   // uses live game-facts.json + board-data.json
   ```
2. **In the row loop** (after `rate`, `netSell`, `inputCost`, `b.wage` are known), replace the single
   `profitPerHour` with paper + realizable, and pull the verdict:
   ```js
   const rz = RZ[kind] || {};
   const realizableRate = rz.realizableRate != null ? rz.realizableRate : rate;   // fallback = paper rate
   const paperPerHour      = (netSell - inputCost) * rate           - b.wage;      // keep for the haircut column
   const realizablePerHour = (netSell - inputCost) * realizableRate - b.wage;
   if ((rz.verdict || '').startsWith('MIRAGE')) { skipped.push([name[kind], rz.verdict]); continue; }
   ```
   push `verdict: rz.verdict, realizableRate, realizablePerHour, realizableFraction: rz.realizableFraction,
   paperPerHour` onto the row.
3. **Sort key** — replace `by === 'profitPerHour'` with `realizablePerHour`:
   ```js
   rows.sort((a,b) => by === 'paybackH' ? a.paybackH - b.paybackH : b.realizablePerHour - a.realizablePerHour);
   paybackH = Math.round(b.cost / Math.max(1, realizablePerHour));   // payback on realizable, not paper
   ```
4. **Columns** — add `verdict`, `frac`, and keep the old paper `$/h` as a dimmed reference so the board
   sees the size of the haircut (aerospace paper $3 849 → realizable $0 tells the whole story).

## 11. Expose to strategist / board
- The CLI writes **`board/.realizable.json`** (`{ byKind, constants, generated }`) each run — the
  strategist (`STRATEGIST.md` loop) and `board/board-workflow.js` read `byKind[kind].{verdict,
  realizableRate, realizableFraction, realizablePerHour_preWage}` directly.
- Board rule of thumb: **only propose scaling `B2B-DEEP` or `RETAIL-OK`(high `A_ret`) targets; never
  build `MIRAGE`/`OVERSUPPLIED`; treat `B2B-THIN` as fill-in only.** `realizableFraction` is the
  headline "% of paper that's real" — anything <0.05 is a lake you can't drain, regardless of $/unit.
- Regenerate `realizable.js` output whenever `board-data.json` refreshes (retail saturation + ticker
  move); `game-facts.json` is static-ish. Re-probe the crude/dough sell-book (§8.1) before committing
  large B2B capex.
