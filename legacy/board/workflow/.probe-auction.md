# Probe: SEND TO AUCTION + PUT ON DISPLAY (2026-07-24, read-only)

Probed live with `probe-auction-display.js` + `probe-display2.js` (both in sim/, standalone
one-session cdp scripts, NO confirm path at all — pure dry-read). Bundle facts from
`bundle-main.js`. Nothing was clicked past dialog-open; no mutations issued.

## 1. Building auctions — SEND TO AUCTION

### Flow (verified live on farm 54959369, lvl 3)
- Building page `/b/<id>/` top row has TWO "SEND TO AUCTION" controls: an `<a
  href="/landscape/buildings/<id>/auction">` and a `<button>` (same action, two renders).
  Clicking is just NAVIGATION to a dedicated page — not a modal, harmless.
- The send page `/landscape/buildings/<id>/auction` (h1 "Send to auction") shows:
  - Bullets: **"Building slot will be freed immediately" / "Auction will last 24 hours" /
    "Minimum bid: $20,700" / "Fee: 20%"**
  - Conditions list: `Requirements not met: Cannot be busy, Level 5`
  - Header banner: **"Your company is too small to participate in building auctions"**
  - Buttons: `CANCEL` (back to building, safe), `SEND TO AUCTION` (**danger, the final
    irreversible action — currently DISABLED**), `DISPLAY SIMILAR AUCTIONS 10` (10-SB
    research unlock, disabled).

### Gates (why we currently CANNOT auction even by accident)
1. Company capability `buildingAuctions` unlocks at the **level-20 tier** in the bundle's
   level table (we are Lv 11 → "too small", final button disabled).
2. Building must be **level >= 5** (`minBuildingLevel:5`); extraction buildings (mines etc.)
   alternatively need an abundance **>= 95** (`minAbundance:95`; levels
   Perfect100/Exceptional98/VeryGood95/Good91/Usable86/Poor80/Trash0).
3. Building **cannot be busy** (producing/selling).

### Cancellation semantics — THERE IS NO CANCEL
- No cancel-auction endpoint or UI string exists anywhere in the bundle (searched). The
  bullet "Building slot will be freed immediately" means the building LEAVES the landscape
  the moment the auction starts and goes to state `AUCTION` for 24 h. **Treat SEND TO
  AUCTION as instantly irreversible — same class as scrap, worse (price set by bidders).**
- Bids, by contrast, ARE cancellable: `DELETE /api/v2/building-auctions/bids/<realmId>/<bidId>/`.

### Mechanics (bundle constants `Ql`)
- `auctionDurationHours: 24`, `auctionFeePercent: 20`, `maxBid: 5e8`.
- **Vickrey auction**: winner pays the 2nd-highest bid; the PA auto-bids up to your max.
- Listing JSON confirms fee: `guaranteedReturn = 0.8 * minBid` (sample: 193200 → 154560).
- Min bid = `building.size * building.cost` (lvl-3 farm → $20,700, i.e. $6,900/level).
- Selling slots: 1 active auction free, simultaneous cost simboosts
  (`sellingSlotsSimboosts: [0,15,30]`); `promoteAuctionSimboosts: 30`;
  `researchUnlockSimboosts: 10` (the "similar auctions" panel).
- Ledger keys: `BUILDING_AUCTION_SOLD / _FEES / _WON / _FINISHED`.

### Endpoints (from bundle route map, GETs verified live)
- `GET  /api/v2/building-auctions/<realmId>/` → `{buildingAuctions:[...]}` — realm 0 had
  398 live. Item shape: `{id, buildingId, buildingKind, buildingSize, realm, startedAt,
  promoted, sellerId, auctionbuildingabundanceSet:[{resourceKind,abundanceLevel}], minBid,
  guaranteedReturn, closesAt, seller:{...}}`.
- `GET  /api/v2/companies/<companyId>/building-auctions/` → ours: `[]` (status 200).
- `POST /api/v2/building-auctions/<realmId>/` body `{buildingId, simboosts:1000}` → CREATE
  auction (what the danger button fires). **Never call directly** — mutations are signed
  with X-Ts/X-Prot bot-protection headers; and it is the catastrophic action anyway.
- `GET/POST /api/v2/building-auctions/bids/<realmId>/` (POST `{buildingAuctionId, amount}`
  = place/raise bid), `DELETE .../bids/<realmId>/<bidId>/` = cancel bid.
- `POST /api/v2/building-auctions/<auctionId>/promote` (30 SB).
- `POST /api/v2/building-auctions/research-by-building/<bId>/` and
  `.../research-by-auction/<aId>/` → `{similarBuildingAuctions}` (10-SB unlock).
- `GET /api/v2/building-auctions/active-unlocks/` → ours `[]`;
  `GET /api/v2/building-auctions/filter-settings/`; browse UI `/market/building-auctions/`.

### Primitive-safety notes (for any future auction action)
- The label "SEND TO AUCTION" appears on BOTH the building page (harmless nav) and the send
  page (final catastrophic submit). A blind text-match clicker WILL confuse them — any
  future primitive must key on `location.pathname` ending in `/auction` AND exclude the nav
  `<a>`, refuse if not exactly one candidate (scrap.js pattern), and stay dry without
  confirm:true. Today the final button is disabled at Lv 11, but do not rely on that.

## 2. Warehouse display case — PUT ON DISPLAY

### Flow (verified live on seeds tile)
- Warehouse tile needs a REAL-MOUSE click (React ignores synthetic; sell-exchange-ui.js
  pattern). Panel URL becomes `/headquarters/warehouse/<slug>` (slug = resource name).
- Panel buttons: `SELL ON THE EXCHANGE`, `SEND CONTRACT`, `PUT ON DISPLAY`, `BLOCK USE`.
- `PUT ON DISPLAY` is a NAVIGATION to `/headquarters/warehouse/<slug>/display/` which
  mounts a modal over the panel:
  - Title: "Put Resource on display"; body: "Do you want to put up Resource on display for
    everyone to see?"
  - Field: checkbox `showAmount` — "Show amount" — **default CHECKED** (shows unit count
    publicly).
  - Confirm: **`YES, PLEASE`** (not clicked). Cancel: **`I changed my mind`** (same label
    as the scrap dialog). No warnings — it is cosmetic.
- **Dismiss gotcha:** the cancel label starts with "I", so `/^(cancel|no|close)/` regexes
  miss it; match `/changed my mind/i` (probe fell back to navigating away, also fine —
  navigation closes the modal with no side effect).

### Semantics
- Display case is the public showcase on the company profile: resources, certificates,
  achievements, NFTs. Purely cosmetic — the resource is NOT locked, sold, or consumed.
- Fully REVERSIBLE: `DELETE /api/v2/companies/me/display-case/<itemId>/` removes an item.
- Max 12 slots; extra slots cost simboosts (server constant `displayCaseSlotCost`, fetched
  at runtime — not in bundle) via `PATCH /api/v2/companies/me/display-case/` — that PATCH
  is the only display call that spends anything; never automate it.

### Endpoints
- `GET  /api/v2/companies/me/display-case/` → ours: `[]` (status 200).
- `POST /api/v2/companies/me/display-case/` body
  `{resource_id | certificate_id | achievement_id | nft_id, show_amount}` — what
  YES, PLEASE fires (signed mutation; go through UI if ever automated).
- `DELETE /api/v2/companies/me/display-case/<itemId>/` — remove (reversible).
- `PATCH  /api/v2/companies/me/display-case/` — unlock extra slot (COSTS simboosts).
