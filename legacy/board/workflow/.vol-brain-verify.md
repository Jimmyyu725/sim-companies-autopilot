1. **price-tracker/collect.js** — `cdp.connect()` without `cdp.close(); process.exit(0)` (LESSONS rule 1). Every 2-min run was killed by its own `timeout 45` after doing the work, holding the shared tick lock the whole time. Fixed and re-run once: clean 10.6 s exit.
2. **brain/brain.js** — the `act` tool enum was `[collect, produce, buy, sell, build, upgrade]` — **no `scrap`**, while BRAIN.md's chairman standing order step 2 explicitly requires `act scrap` and act.js implements it. The model could NEVER have executed the Slaughterhouse scrap. Added `'scrap'` to the enum and to BRAIN.md's Tools list.
3. **brain/BRAIN.md** — mixed-language fragment "Check cash每wake" in an English doc (project rule 2). Fixed to "Check cash every wake".
